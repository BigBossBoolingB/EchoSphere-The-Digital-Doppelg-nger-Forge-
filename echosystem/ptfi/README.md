# Persona Training & Feedback Interface (PTFI)

This service provides an API for users to interact with the analysis results generated by the MAIPP module. It forms the core of the human-in-the-loop refinement process.

## Functionality

- Provides a `GET /analysis/{request_id}` endpoint to retrieve a specific analysis document from the Persona Knowledge Graph (PKG).
- Provides a `POST /analysis/{request_id}/refine` endpoint for users to submit feedback and refinements.
- On successful refinement, it updates the analysis document in the PKG and sends a `RefinementEvent` to an SQS queue to trigger the retraining process.

## Environment Variables

- `MONGO_URI`: The connection URI for the MongoDB database.
- `MONGO_DB_NAME`: The name of the database to use.
- `REFINEMENT_SQS_QUEUE_URL`: The URL of the SQS queue for refinement events.
- `AWS_REGION`: The AWS region for the SQS service.
